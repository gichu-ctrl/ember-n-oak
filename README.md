# Ember & Oak: coffee shop site (Next.js 14 + Tailwind CSS 3)

    npm install
    npm run dev      # http://localhost:3000

- Business details and hours: `data/site.ts`
- Placeholder menu: `data/menu.ts`
- Colours: `tailwind.config.ts` (espresso, roast, mocha, caramel, crema, cream)
- Contact form posts to `app/api/contact/route.ts`, which currently logs the message. Connect an email service there.
